# Időmérő rendszer

A távlovas sportban használandó időket számitja amit jelenleg még manuálisan viszünk fell dee a jövöben python kod meg fogja könyiteni és automatizálni

## Leírás

Szoval a projektem arról szól hogy egy időmérő rendszert programoztam és folytatnám ebbe esetleg ha olvasod bele kerülsz és együt csinálnánk

## Kezdjünk bele

### Jelenlegi állás

* Elsőnek alapból a projektem az HTML CSS és JS kodokban írododt és hamarosan egy Python kod is böviteni fogja ami a fizikai rendszeremet fogja müködtetni és adatot lekérni és továbitani a webnek blocks for commands
